Source code of the LGPL components is available at the URLs above. You may replace any LGPL
component with your own modified build: the extender loads them by file name only.

Unity engine libraries are NOT included. On the first start BepInEx downloads them from
https://unity.bepinex.dev (its default setting) to generate the game wrappers.
